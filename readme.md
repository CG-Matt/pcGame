# PC Game

Small unfinished terminal-based game involving navigating a computer network.

## Running Instructions

### Dependencies
The following dependencies are requied for this program:
```
Node.js (Tested with version 18.20.6)
npm (Tested with version 9.2.0)
tsc (Tested with version 5.6.3)
```

### Running the program

To install and compile the TypeScript:
```console
$ git clone https://www.github.com/CG-Matt/pcGame
$ cd pcGame
$ npm install
$ tsc
```

To run the program simply open it with node:
```console
$ node .
```
